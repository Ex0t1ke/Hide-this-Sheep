# Hide this Sheep 🐑🐺

A charming and strategic Android puzzle game where your main goal is to protect your fluffy sheep from a sneaky wolf! Place fences, build defenses, and solve engaging grid-based puzzles across multiple levels.

## 🎮 Gameplay
- **Strategic Puzzles:** Place fences and gates on the grid to create a safe path or enclose the sheep.
- **Dynamic Entities:** Interact with the Sheep and the Wolf, using logic to outsmart the predator.
- **Level Progression:** Play through a fully featured Campaign Mode with varying difficulties and setups.
- **Rating System:** Complete levels efficiently to earn 1 to 3 stars.

## ✨ Features
- Beautiful 3D-styled cartoon UI and custom graphics.
- Interactive and animated `GameView` canvas.
- Original sound effects and atmospheric background music.
- Built-in Tutorial mode to get you started.
- Settings menu with audio controls and preferences saving.

## 🛠 Tech Stack
- **Platform:** Android
- **Language:** Java
- **UI System:** Android XML Views (ConstraintLayout, Custom Views)
- **Architecture:** Custom Game Loop and state management (`GameState`, `GameView`)

## 🚀 How to Run
1. Clone this repository.
2. Open the project in **Android Studio**.
3. Let Gradle sync and build the project.
4. Hit **Run** (`Shift + F10`) to deploy to your emulator or physical device.
